Ocean bitmap A*

The same stages as maritime-routing: a regular lon/lat grid, land blocked, eight-direction A* with a great-circle heuristic, then a string pull that straightens any span whose corridor is all water. A sketch leaves from the boundary cell with the shortest water path, not from its center. Cells are read from the land archive as the search reaches them, so a fine grid does not have to load the whole window. On the last frame the red grid path hides; gray is the raw centerline and color is the string-pulled route.
