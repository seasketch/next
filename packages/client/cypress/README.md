# Cypress specs, kept for reference

These specs are not runnable. Cypress, its plugins, and its configuration were removed in October 2026; the browser suite is Playwright in `packages/e2e`. The onboarding and smoke journeys here are kept only as a description of behavior to port. When a journey has a Playwright equivalent, delete its spec here. `support/commands.ts` and the helpers next to it are the custom commands the specs call, kept so the specs read on their own.
